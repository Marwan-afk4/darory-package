## Installation

To install this package via Composer, first add the following to your `composer.json` file:

```json
"repositories": [
    {
        "type": "vcs",
        "url": "https://github.com/Marwan-afk4/darory-package.git"
    }
]

To install this package via Composer, first add the following to your `auth.json` file:

```json
{
    "github-oauth": {
        "github.com": "your_github_personal_access_token"
    }
}
